# hxyfront-62008 烟花燃放脚本编排

源提示词编号：10

面向烟花燃放编排师的燃放脚本前端工具：记录节目段落、烟花型号、口径、发射角度、点火时间、持续时间、安全距离和音乐时间点，提供时间轴编排、燃放点位平面图、型号清单、冲突时间提示和整场节目预览。

## 技术栈

React + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62008

## 核心行为（改一处牵动全场）

所有视图共享同一份数据源，任何修改都经 `computeSchedule` 全量重算（`src/engine/schedule.ts`）：

- **音乐点改动 → 节点重算**：时间轴或段落编辑器中修改音乐时间点，绑定它的点火节点全部重算；手工「钉住」的节点留在原处不动。
- **模块容量与排队**：点火模块通道数有限，本点位排不下的节点依次排队等下一台模块；同台模块两次点火间隔不足最小间隔时自动顺延。
- **模块掉线重排**：模块掉线后其节点按其余模块余量重排；重排失败的节点按原节点（原模块、原时间）重试并标红告警。
- **并发保存**：段落带版本号。两名编导同时编辑同一段落时，先保存的落库，晚保存的收到逐项差异列表（字段 / 我的修改 / 已保存值）。
- **平面图**：燃放点位平面图标出每台模块的余量（绿/黄/红/灰）、间隔冲突徽标（顺延/排队/重试）和落点安全距离圈（越界变红）。

## 页面结构

- 时间轴编排：段落泳道、音乐点、节点状态（正常/顺延/排队/重试/钉住），点击即可编辑
- 燃放点位平面图 + 整场节目预览（6 倍速播放、拖拽进度）
- 段落编辑（含版本提示与冲突弹窗）、点火模块、冲突提示、型号清单
